# Synthetic Data Platform

A configurable, reproducible Python platform that generates realistic, related
business datasets (customers, orders, payments, events) as a stable data source
for data engineering projects (ETL, warehouse, streaming, CDC, data quality).

## Status
Phase 0 - foundations. Progress: docs/roadmap.md

## Run
`python main.py` - currently a logging smoke test; generation starts Milestone 2.
